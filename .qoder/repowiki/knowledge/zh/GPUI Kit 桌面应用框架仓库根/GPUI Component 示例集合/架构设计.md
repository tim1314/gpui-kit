examples 是扁平的示例仓库根，每个子目录（如 editor、dock、webview、js_story、ai_recipes 等）都是一个自包含的独立包：Rust 示例通过各自的 `Cargo.toml` 声明对 `gpui-kit.workspace = true` 的依赖并以 `src/main.rs` 为入口；JavaScript 示例（js_story、js_todolist、js_webview、js_dock）使用 `jsconfig.json` + ES module 组织，其中 js_story 作为组件故事画廊被 gpui-shell 在 `components` feature 下消费。共享资源集中在 `fixtures/`（多语言测试文档）和顶层 `color_mix_oklab.rs`。ai_recipes 是唯一同时拥有 `tests/` 集成测试与 `recipes.json` 配置的可发布示例包（`publish = false`），并通过 `features = ["test-support"]` 启用测试 harness。所有 Rust 示例统一遵循 README 约定的启动路径：先调用 `gpui_kit::init(cx)`，再通过 `gpui_kit::open_window(options, cx, build)` 打开窗口并挂载 Base Root。
