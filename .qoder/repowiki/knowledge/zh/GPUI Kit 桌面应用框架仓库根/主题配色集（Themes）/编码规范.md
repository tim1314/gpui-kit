- 每个主题文件以 `$schema` 字段指向仓库中的 `.theme-schema.json`，并附带 `name`、`author`、`url` 元信息。
- 一个文件通过 `themes` 数组承载同一主题家族的多个变体（如 Gruvbox Light/Dark、Tokyo Night/Storm/Moon），各变体通过 `mode` 区分明暗。
- UI 语义色统一放在 `colors` 下，基础六色通过 `base.red/green/yellow/blue/magenta/cyan` 暴露，供其他语义键复用。
- 语法高亮集中在 `highlight.syntax` 下，按 token 名（如 `keyword`、`string`、`comment.doc`）映射到含 `color` 的对象，样式属性（`font_style`、`font_weight`）作为可选附加字段。
