站点以 Astro 7 为框架，采用 `src/pages` + `src/layouts` + `src/components` 的标准分层：
- 内容层：`base/`、`component/`、`docs/`、`shell/` 四个英文文档目录及其 `zh-CN/` 镜像，通过 `src/content.config.ts` 用 `astro:content` 的 `defineCollection` + `glob` loader 注册为 `docs/component/shell/base` 及 `zh-*` 集合，统一使用含 `title/description/order/example/exampleKind/maturity` 字段的 schema。
- 路由层：`src/pages/{docs,component,shell,base}/[...slug].astro` 配合对应的 `[...slug].md.ts` 数据文件，以及 `zh-CN/` 下相同结构的多语言路由；首页、`apps`、`releases`、`contributors`、`skills` 等静态页面位于根级 `pages/`。
- 布局与组件：`BaseLayout.astro` / `DocsLayout.astro` / `HomeLayout.astro` 三套布局，Vue 3 组件（如 `ComponentExample.vue`、`Sidebar.astro`、`Toc.astro`）通过 `@astrojs/vue` 集成渲染。
- Markdown 处理链：在 `astro.config.mjs` 中通过 `unified()` 显式启用 Sätteri 处理器，串联 remark 插件（`remarkMath`、`remarkSnippets`、`remarkCallouts`、`remarkComparisonStatus`、`remarkDocVariables`、`remarkMaturity`、`remarkDocLinks`）与 rehype 插件（`rehypeMathjax`、`rehypeHeadingIds`、自定义 `rehype-heading-anchors.js`），Shiki 主题从 `src/light.theme.json` / `dark.theme.json` 读取以保证代码高亮与站点 chrome 一致。
- 搜索与部署：通过 `astro-pagefind` + `pagefind` CLI 在 build 后生成静态搜索索引；`public/` 存放 SVG 资源、OG 模板、CNAME 与 shell 安装脚本；`astro.config.mjs` 动态计算 `PUBLIC_SITE_BASE` 并生成旧版 `/docs/components/*` → `/component/*` 重定向，支持版本化部署（`SITE_OUT_DIR`）。
- 测试：`tests/` 下使用 Bun 原生测试运行器对 showcase 浏览器、SEO、链接、Markdown 渲染、发布版本等进行验证。
