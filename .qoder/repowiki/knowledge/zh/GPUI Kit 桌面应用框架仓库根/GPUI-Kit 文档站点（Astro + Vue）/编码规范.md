- 每个文档集合（docs/component/shell/base 及其 zh-CN 镜像）在 `content.config.ts` 中以相同的 `pageSchema` 定义，并通过 `glob({ pattern: '**/*.md', base })` 加载。
- 路由采用 Astro 的 `[...slug].astro` + `[...slug].md.ts` 成对模式，分别负责页面渲染与前端数据导出。
- Markdown 扩展能力以独立的 `remark-*` / `rehype-*` 插件形式放在 `src/lib/` 下，并在 `astro.config.mjs` 的 unified pipeline 中集中注册。
- Shiki 主题不硬编码，而是从 `src/light.theme.json` / `dark.theme.json` 读取，由 `markdown.js` 的 `shikiConfig` 暴露给 Astro 与 releases 渲染器共享。
- 多语言站点通过在英文目录外复制一份 `zh-CN/` 镜像，并在 `astro.config.mjs` 的重定向逻辑中同时处理 `''` 与 `'zh-CN/'` 前缀来保持行为一致。
