模块由两个并列的 SKILL 子目录组成，每个子目录遵循统一的 `SKILL.md` + `references/` 结构：
- `gpui-kit/SKILL.md` 是主技能入口，声明名称、描述与前置阅读顺序（先 Design Guides，再 Coding Guides），并通过表格索引 references 下的 coding-guides、conventions、recipes、usage 以及 gpui 机制参考（action/async/context/entity/event/focus/global/layout-style/test 等），同时内置完整的组件目录（Input/Form、Display、Overlay、Navigation、Data Display、Chat、Charts）和测试指引。
- `gpui-kit-design-guides/SKILL.md` 是设计侧配套技能，指向 `references/design-guides.md`，规定视觉语言、布局模式、交互状态、覆盖层、动效、数据密集界面与界面文案的设计规则。
两个技能通过相互引用形成依赖方向：coding guides 引用 design guides，design guides 回指 coding guides；当本地文件缺失时，SKILL.md 明确给出从 `https://gpui-kit.com/docs/` 拉取对应 Markdown 的降级路径。模块本身不含 Rust 源码，仅承载面向 LLM 的结构化知识。
