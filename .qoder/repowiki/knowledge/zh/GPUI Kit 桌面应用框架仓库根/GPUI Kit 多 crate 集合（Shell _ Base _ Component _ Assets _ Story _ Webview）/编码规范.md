- 可选能力通过 Cargo feature 组合（如 gpui-fast、components、webview、quickjs、tree-sitter-*、speech、inspector、decimal），并在依赖处以 `dep:` 形式声明，避免隐式激活。
- 平台相关实现通过 `#[cfg(target_os = "...")]` 与 `#[cfg(not(target_family = "wasm"))]` 拆分到独立文件或依赖段，WASM 与 native 分支分别列出依赖。
- 图标资源采用 build.rs 扫描 SVG 目录生成 Rust 枚举与内嵌字节数组，并通过 `cargo:icons-dir=` 与 `cargo:rustc-env=` 向 proc-macro 传递路径。
- 公共 API 集中在每个 crate 的 `lib.rs` 顶层 `pub use` 重导出，内部模块保持 `pub(crate)`，仅把稳定契约暴露给宿主与应用。
- 组件通过 `component-macros` 提供的 `icon_named!` 与 `IntoPlot` derive 在编译期生成枚举与类型转换，避免运行时代码扫描。
